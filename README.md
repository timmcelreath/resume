# Tim McElreath

Portfolio and résumé for Tim McElreath, VP of Engineering, Member Growth at Spring Health.

- `index.html`: works (Criteria, Kinopolis, Colossal Cave, Old Lady Mahjong)
- `resume.html`: résumé, served at `/resume`
- `styles.css`: shared styles

Plain static HTML and CSS with no build step. Hosted on Vercel; `vercel.json` turns on clean URLs. To preview locally:

```sh
python3 -m http.server
```
